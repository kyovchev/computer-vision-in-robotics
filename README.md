# Computer Vision in Robotics Book Examples

This repository contains source code of the examples for the book Computer Vision in Robotics.

The repository contains separate folders for each chapter of the book.

Images were captured by multiple different cameras.

For the AI training and inference a Windows laptop computer is used with the following specifications:
- CPU: 12th Gen Intel(R) Core(TM) i7-12700H (2.70 GHz)
- RAM: 32 GB
- GPU: NVIDIA GeForce RTX 3050 Ti Laptop GPU (4 GB)

The code was executed in a virtual environment in Anaconda 2.7.1 with Python 3.11.16.
